01 / A ideia

É uma banca de jornal, não a internet inteira

Você chega numa banca e pede: “o que saiu sobre inflação?”. A pessoa olha as manchetes e os resumos. O que combina, ela separa. O que não combina, fica na prateleira. Só depois você leva para casa as edições escolhidas.

01

Você indica a banca

O comando precisa do endereço de um site de notícias ou do feed dele (RSS ou Atom). Ele não abre o Google sozinho e não adivinha qual jornal ler.

02

Ele compara palavras

A busca olha o título e a descrição curta. Se a palavra aparece no título, na descrição, ou nos dois, a página entra na lista. Não é uma leitura “que entende o assunto” como uma pessoa.

03

Você escolhe o que guardar

A lista volta para você — ou para o modelo de IA, se ele estiver rodando o comando. Quem guarda de fato é o segundo comando, e só nos endereços escolhidos.

Uma frase para repetir

“Discover mostra o que combina. Collect guarda no projeto.”

02 / Na prática

Um exemplo, do começo ao fim

Imagine que você está na pasta do seu projeto e quer notícias sobre inflação no feed de um jornal. O endereço abaixo é de mentira (example não é um site de verdade). Troque pelo feed ou pela página inicial do jornal que você quer ler.

O ponto . significa “esta pasta”. Os arquivos nascem aqui, dentro de researchs/.

Passo 1 — montar a lista

aioson web:discover . --query="inflação" --url=https://noticias.example/rss --json --out=researchs/inflacao/discover.json

Em linguagem comum: “nesta pasta, procure inflação nesse feed, responda em JSON e grave a lista em researchs/inflacao/discover.json”.

O que uma resposta boa parece

Inflação recua no mês — combinou no título. Endereço https://noticias.example/inflacao-recua.

Pixel show abre — a descrição cita inflação, então também entra. O título sozinho não falava do assunto.

Campeonato de xadrez — não entra. Nem o título nem a descrição falam de inflação.

A resposta também traz um campo collect.example. É o próximo comando, já escrito, para quem estiver lendo o JSON — inclusive um modelo de IA.

Por que “pix” não acha “pixel”

A comparação é pela palavra inteira. pix não casa com pixel. inflação casa com Inflação, com ou sem acento.

Passo 2 — guardar só o que interessa

Para salvar uma matéria:

aioson web:collect . --slug=inflacao --urls=https://noticias.example/inflacao-recua

Para salvar duas, separe os endereços por vírgula, sem espaço obrigatório:

aioson web:collect . --slug=inflacao --urls=https://noticias.example/inflacao-recua,https://noticias.example/economia-digital

Para guardar todas as que o discover achou, aponte o arquivo da lista. Isso salva cada candidato daquele arquivo, até 8 páginas:

aioson web:collect . --slug=inflacao --candidates=researchs/inflacao/discover.json

--slug é o nome da pasta. Use um nome do assunto, curto, sem espaço: inflacao, eleicoes, safra. O comando tira acentos e caracteres estranhos sozinho.

Se o comando aioson não existir no seu computador

Use npx @jaimevalasek/aioson no lugar de aioson. O resto da linha fica igual.

03 / Onde ler depois

Abra o resumo antes do texto inteiro

Depois do collect, a pasta do assunto fica assim:

  • researchs/inflacao/summary.mdO resumo. É o primeiro arquivo para uma pessoa ou para o modelo. Diz o que foi salvo e de onde veio.
  • researchs/inflacao/links.mdA lista legível: título, endereço e arquivo de cada matéria.
  • researchs/inflacao/links.jsonA mesma lista em formato de dados, para outro comando ler.
  • researchs/inflacao/files/01-inflacao-recua.mdO texto da página. Um arquivo por matéria.
  • researchs/inflacao/discover.jsonSó aparece se você usou --out no discover. É a lista, antes de escolher o que guardar.

O texto da página é de outra pessoa. O arquivo avisa que ele é informação, não uma ordem. Se a página tentar dizer ao modelo o que fazer, isso continua sendo texto da página — não uma instrução sua.

Se alguma página falhar, as outras ainda são salvas. O resumo marca isso como has-alternatives. Quando todas entram, o veredito é confirmed.

04 / A família web

Qual comando usar em cada situação

Discover e collect são o caminho de notícia. Os outros quatro servem para outra pergunta.

O que cada comando faz, em uma frase
ComandoUse quandoNão use quando
web:discoverVocê tem um site ou um feed e quer a lista do que combina com uma busca.Você já sabe o endereço exato da matéria.
web:collectVocê já escolheu os endereços e quer o texto no projeto.Você quer copiar o visual do site, com CSS e imagens.
web:scrapeVocê quer ver o texto de uma página agora, na tela, sem criar arquivo.Você quer guardar para ler amanhã. Ele não salva em researchs/.
web:mapVocê quer a lista de páginas internas de um site, como um mapa.Você quer filtrar por assunto. O mapa não recebe uma busca.
web:saveO site é referência de visual: fontes, cores, movimento. Ele espelha os arquivos em researchs/nome/site/.Você só quer o texto de uma notícia. Esse comando é pesado de propósito.
web:extractO site já foi salvo com web:save e você quer um resumo de design, não o HTML cru.Você ainda não salvou o site.

Ver o texto de uma página, sem guardar:

aioson web:scrape . --url=https://noticias.example/inflacao-recua --format=markdown

Copiar um site como referência visual:

aioson web:save . --url=https://estudio.example --slug=estudio
Não misture os nomes

web:save e web:collect podem usar a mesma pasta researchs/nome/. Se o nome for o mesmo, o resumo de um substitui o resumo do outro. Para notícia, use o assunto (inflacao). Para visual, use o nome do site (estudio).

05 / Limites

O que estes comandos não fazem

  • Não pesquisam a internet inteira. Sem um endereço, o discover só funciona se o projeto tiver um serviço configurado em AIOSON_RESEARCH_PROVIDER_URL. Sem isso, a mensagem pede um --url.
  • Não entendem sinônimo. “Carro” não acha “automóvel”, a menos que essa palavra também esteja no título ou na descrição.
  • Uma palavra compartilhada não é o assunto. “modelos llm” também encontra “10 modelos” de fone. Com o Jev ligado em .aioson/config/aioson-models.json, o comando pergunta se a matéria é sobre a busca. Sem resposta do Jev, a lista continua por palavra e quem lê o JSON precisa conferir antes de guardar.
  • Não leem página que só existe depois do JavaScript. Se a manchete não está no HTML ou no feed, ela não entra na lista.
  • Não abrem endereço da sua própria máquina. localhost e IPs privados são recusados antes do download. Isso vale para discover e collect.
  • Guardam no máximo 8 páginas por collect e devolvem no máximo 20 candidatos no discover (--limit, padrão 8).
  • Não publicam o texto de volta na internet. A pasta é referência local do projeto.

06 / Para consultar

Palavras que aparecem na tela

Feed, RSS, Atom
Uma lista pronta do site, com título, resumo, data e link de cada matéria. É o melhor endereço para passar em --url.
Query
O texto da sua busca. No comando, fica em --query="inflação".
Slug
O nome curto da pasta, sem espaço. inflacao vira researchs/inflacao/.
matched_in
Onde a busca encontrou a palavra: title, description ou os dois.
score
Um número de relevância. Título pesa mais que descrição. Empate: a data mais nova vem primeiro, se o site informou a data.
candidates
A lista de páginas que passaram na busca. Ainda não estão salvas.
JSON
Um texto estruturado, fácil para um programa ou um modelo ler. --json pede essa forma.

Dúvidas frequentes

Preciso decorar os dois comandos?

Não. O discover, com --json, devolve o comando de collect pronto no campo collect.example. Se um agente estiver na conversa, ele pode ler essa lista e chamar o collect só nos endereços escolhidos.

E se eu não souber o endereço do feed?

Passe a página inicial do jornal em --url. Se ela apontar para um feed, o comando segue esse link. Se não apontar, ele lê os títulos e resumos que já estão no HTML da página.

Posso ver a ajuda sem rodar nada?

Sim. aioson web:discover --help e aioson web:collect --help mostram as opções e não baixam página nenhuma.

A busca é semântica, como um modelo de IA?

Por padrão, não. Ele compara palavras do título e da descrição. Em .aioson/config/aioson-models.json basta preencher jev.api_key. Com a chave, o discover pergunta ao Jev se a matéria é sobre a busca. Com o campo vazio, a lista continua por palavra.

Onde está a documentação curta dos comandos?

Na referência comandos do CLI, na seção Web nativa. Este guia é a versão para quem está começando.

Os endereços noticias.example e estudio.example são de exemplo. Nenhum site real foi consultado para escrever este guia. O comportamento descrito segue web:discover e web:collect neste repositório, versão 1.67.0, em 21 de setembro de 2026.
