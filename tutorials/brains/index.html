01 / Conceito

O que é um Brain, afinal?

Um Brain é uma coleção curada de conhecimento procedural. Enquanto a documentação comum costuma ser prolixa e dispersa, os nós de um Brain são escritos diretamente para consumo por modelos de inteligência artificial:

A

Receitas Determinísticas

Instruções passo a passo de como resolver problemas recorrentes (ex: como estruturar CSS tokens com suporte a dark/light sem reescrever seletores).

B

Armadilhas Evitadas (Gotchas)

O registro explícito do que já quebrou antes: "não use biblioteca X junto de Y sob Node 24 devido a vazamento de memória em streams".

C

Nota de Corte de Qualidade (q ≥ 4)

Nenhum nó entra no catálogo oficial sem demonstrar valor prático repetido. Dicas rasas ou óbvias são descartadas automaticamente.

02 / Estrutura interna

A anatomia de um nó procedural.

Cada nó é armazenado em formato padronizado com metadados para busca e avaliação:

id
site-forge/tokens-dark-first
summary
Definição de design tokens onde o tema escuro (tinta) é o padrão e o tema claro (porcelana) apenas inverte luminosidade dos slots sem alterar nomes de variáveis.
tags
css design-tokens dark-mode theme-contrast
quality_score
5 / 5 (provado em produção em mais de 10 projetos com 100% de conformidade WCAG AAA)
recipe
Declarar :root { --tinta: #0b0a08; --marfim: #f5f1e8; } e inverter em [data-theme="light"] { --tinta: #f1ede3; --marfim: #1c1710; }. O código de aplicação consome apenas var(--tinta).
gotchas
Nunca utilizar nomes como --dark-bg ou valores hexadecimais soltos nas classes de componentes.

04 / Eficiência

Carregamento lazy: economia estrita de tokens.

Em vez de despejar dezenas de páginas de manuais no contexto do modelo, o AIOSON executa uma busca semântica em duas etapas:

01 · Intenção

Agente se ativa

O @site-forge precisa construir um novo card de produto acessível.

02 · Filtro

Tags de Domínio

O kernel filtra nós que possuem as tags css e a11y.

03 · Corte

Filtro de Qualidade

Descarta nós com nota inferior a 4 ou marcados como rascunho.

04 · Briefing

Injeção Mínima

Apenas o trecho da receita entra no prompt, consumindo menos de 300 tokens.

06 / Extensão

Como criar um Brain para o seu domínio de negócio.

Se o seu projeto lida com regras específicas (ex: faturamento médico, integrações tributárias ou rotinas financeiras), você pode criar um brain dedicado:

1

Crie a pasta do brain em .aioson/brains/{nome}/

Exemplo: .aioson/brains/financeiro/ com um arquivo de manifesto e nós em Markdown.

2

Defina nós com receitas práticas e gotchas reais

Explique como calcular taxas, validar chaves PIX ou montar conciliação bancária.

3

Atribua as tags correspondentes e a nota de qualidade

Qualquer agente que tocar arquivos desse módulo consultará o brain automaticamente.
