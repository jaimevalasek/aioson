01 / Princípio

O modelo raciocina; o AIOSON lembra.

Modelos de linguagem não aprendem durante uma conversa: eles processam tokens de entrada e geram saída. Se você não fornecer o histórico relevante, o modelo começa no vácuo.

A solução do AIOSON é transformar o disco do projeto no caderno de trabalho oficial. Em vez de depender do histórico de um provedor específico de IA, o estado é materializado em arquivos Markdown padronizados e tabelas relacionais locais.

Regra de Ouro do Contexto

Nenhum agente carrega todos os arquivos de uma vez. O comando aioson context:brief seleciona exclusivamente as regras e aprendizados vinculados aos arquivos e tarefas que estão sendo tocados no momento.

03 / Memória da pessoa

Operator Memory: suas preferências acompanham você.

Você prefere comentários curtos em português? Não quer que o agente instale dependências sem confirmação expressa? Já corrigiu o mesmo vício de escrita três vezes?

A Operator Memory (armazenada em ~/.aioson/operators/{sha256(git-email)[0..16]}/) captura as decisões, autorizações e correções do operador humano, reutilizando-as em qualquer repositório onde você abrir o AIOSON:

Sinal Capturado Exemplo Real Efeito na Sessão
authorization "Pode rodar comandos de git status sem pedir confirmação." O agente atua sem interromper em comandos previamente liberados.
exclusion "Nunca altere o arquivo de variáveis de ambiente .env." Qualquer tentativa de edição desse arquivo é bloqueada preventivamente.
correction "Não crie componentes com nomes em minúsculas." Registrado como regra pessoal que o @dev consulta antes de codificar.
confirmation Repetição de preferência por duas vezes consecutivas. Promovido automaticamente a padrão permanente do operador.
cli · gerenciando a memória do operador
# Listar sinais e preferências conhecidas do operador ativo $ aioson op:list --json operator 7a3f81b2... (git: jaime@dev) signals 4 authorizations · 2 exclusions · 3 corrections # Capturar uma nova autorização de forma determinística $ aioson op:capture --signal=authorization --quote="autorizo npm test" --source-agent=@dev ✓ signal recorded · saved in ~/.aioson/operators/7a3f81b2/MEMORY.md

04 / O Ciclo

O Reflect Engine: como um erro vira memória perene.

Quando um agente conclui uma entrega ou uma feature é fechada, o Reflect Engine entra em ação silenciosamente para destilar o que aconteceu:

01 · Ação agent:done

O agente finaliza

O @dev entrega o código ou o @qa encerra o relatório de testes da unidade.

02 · Exame diff audit

Auditoria de Diffs

O motor compara os arquivos modificados no git contra o orçamento estipulado no plano.

03 · Extração learning capture

Captura de Gotchas

Erros corrigidos e armadilhas contornadas são resumidos em uma frase e indexados.

04 · Escrita INDEX.md sync

Atualização do Índice

A nova receita entra no .aioson/learnings/INDEX.md para consultas imediatas.

05 · FTS5 Index sqlite update

Indexação no Banco

O SQLite atualiza os vetores de busca de texto completo para a próxima chamada de agente.
